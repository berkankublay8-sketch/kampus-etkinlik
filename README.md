# 🎓 Kampüs Etkinlikleri

**Web Teknolojileri ve Programlama 

Kampüs içindeki seminer, atölye ve söyleşilerin listelenebildiği, etkinlik detaylarının görüntülenebildiği ve etkinlik formlarının kullanılabildiği web uygulamasının HTML iskeleti.

Bu proje, Web Teknolojileri ve Programlama dersi kapsamında geliştirilmiştir.
