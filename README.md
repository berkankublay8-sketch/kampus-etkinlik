# 🎓 Kampüs Etkinlikleri

**Web Teknolojileri ve Programlama | Sprint 1 — HTML ve Git**

Kampüs içindeki seminer, atölye ve söyleşilerin listelenebildiği, etkinlik detaylarının görüntülenebildiği ve etkinlik formlarının kullanılabildiği web uygulamasının HTML iskeleti.

Bu proje, Web Teknolojileri ve Programlama dersi kapsamında geliştirilmiştir.

## 🌐 Canlı Demo

🚀 [Kampüs Etkinlikleri — Canlı Site](https://kampus-etkinlik-lvmg.vercel.app)

## 🛠️ Kullanılan Teknolojiler

- **HTML5:** Sayfa yapısı ve semantik etiketler
- **Git:** Sürüm kontrolü
- **GitHub:** Kaynak kod yönetimi
- **Vercel:** Web sitesinin yayımlanması

> Sprint 1 kapsamında CSS ve JavaScript kullanılmamıştır.

## 📁 Proje Yapısı

```text
kampus-etkinlik/
└── sprint1/
    ├── index.html
    ├── etkinlikler.html
    ├── etkinlik-detay.html
    ├── etkinlik-ekle.html
    ├── etkinlik-guncelle.html
    ├── afis.svg
    ├── README.md
    └── .gitignore
```

## 📋 Sayfalar ve Özellikler

| Sayfa | Açıklama |
|---|---|
| Ana Sayfa | Yaklaşan kampüs etkinlikleri |
| Etkinlikler | Etkinliklerin listelenmesi |
| Etkinlik Detay | Etkinlik afişi ve detaylı bilgiler |
| Etkinlik Ekle | Yeni etkinlik formu |
| Etkinlik Güncelle | Mevcut bilgilerle doldurulmuş güncelleme formu |

### Sprint 1 Kapsamı

- Beş HTML sayfası ve aralarında bağlantılar
- Semantik HTML5 etiketleri
- Tablo ve etkinlik listeleri
- Etkinlik afişi
- `label` ile ilişkilendirilmiş form alanları
- Zorunlu alanlar için `required` kullanımı
- GitHub üzerinden sürüm kontrolü
- Vercel üzerinde canlı yayımlama

**Not:** Bu sprint yalnızca HTML iskeletini içerir. Formlar henüz verileri kalıcı olarak kaydetmez veya güncellemez.
