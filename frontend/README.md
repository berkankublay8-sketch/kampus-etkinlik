# Kampüs Etkinlikleri — Sprint 6 + Vize

## Kurulum

```bash
npm install
npm run dev
```

## Route listesi

- `/` → HomePage
- `/events` → EventsPage
- `/events/:id` → EventDetailPage
- `/login` → LoginPage
- `/register` → RegisterPage
- `/forgot-password` → ForgotPasswordPage
- `/admin` → AdminPage
- `/admin/new` → AddEventPage
- `/admin/:id/edit` → EditEventPage
- `*` → NotFoundPage

React Router, dinamik Header, Context, controlled form, doğrulama, ekle-güncelle-sil, arama/filtre ve mobil yönetim tablosu bu sürümde tamamlanmıştır.
